## Project Description

Mini Spotify Capstone is a web-based music player application developed using HTML, CSS, and JavaScript. The application allows users to browse and play music tracks through an interactive and user-friendly interface. It also includes an admin panel for managing song data stored using JSON Server.

## Features

* Browse available songs
* Play and pause music
* Responsive user interface
* Song data management using JSON Server
* Admin panel for song management
* Dynamic content loading using JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript
* JSON Server

## How to Run the Project

1. Download or clone the repository.

2. Open the project folder in Visual Studio Code.

3. Install JSON Server (if not already installed):

   npm install -g json-server

4. Start the JSON Server:

   npx json-server --watch db.json --port 3000

5. Open `index.html` in your browser or run the project using Live Server.

6. Ensure JSON Server is running before using features that require data from `db.json`.
